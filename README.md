# ✈️ LAX Flight Delay & Cancellation Analysis (Excel Project)

## 📌 Project Overview
This project analyzes flight operations at Los Angeles International Airport (LAX), one of the busiest airports in the United States.

Using Microsoft Excel, flight delay and cancellation data was cleaned, transformed, and analyzed to generate insights for airport management and reporting to the Federal Aviation Administration (FAA).

---

## 🎯 Business Objective
- Analyze flight delays and cancellations  
- Evaluate airline performance  
- Identify monthly trends  
- Support decision-making with data insights  

---

## 🛠 Tools & Skills Used
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Calculated Columns  
- Data Cleaning & Transformation  
- Data Modeling (Table Relationships)  
- Lookup Functions (VLOOKUP / INDEX-MATCH)  

---

## 📂 Dataset Summary
- Total Flights: **4,985**  
- Total Delays: **975**  
- Average Delay: **51.9 minutes**  
- Total Cancellations: **52**
